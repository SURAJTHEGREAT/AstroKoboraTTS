# Voice Blending

Kokoro TTS supports the creation of custom voices through voice blending, allowing users to synthesize speech that combines the vocal characteristics of two different speakers.

## The Blending Process

Voice blending in Kokoro is performed by mathematical interpolation between the speaker embeddings (styles) of two base voices.

### 1. Selection and Configuration
An administrator uses the frontend UI or hits the `/api/blend` endpoint via POST. The request is a JSON payload containing:
- Admin credentials (for authorization).
- `voiceName`: A unique string identifier for the new blended voice.
- `voiceA`: The ID of the first base voice (e.g., `af_heart`).
- `voiceB`: The ID of the second base voice (e.g., `am_adam`).
- `ratio`: A float between 0.0 and 1.0 representing the blend ratio (0.0 is 100% Voice A, 1.0 is 100% Voice B).

### 2. Processing and Storage
When the backend receives the request, it performs the following:
- **Validation**: Checks if the requested `voiceName` is unique and the credentials are valid.
- **Database Tracking**: A new record is inserted into the SQLite `voices` table, saving the `voice_name`, the base voice IDs (`voice_a`, `voice_b`), the `ratio`, and setting `is_blended` to `True`.

### 3. Usage During Synthesis
When a subsequent request is made to `/api/tts` specifying the newly created blended voice:
1. The system looks up the record in the `voices` database.
2. It identifies that the voice is a blended voice.
3. It retrieves the native speaker embeddings for both `voice_a` and `voice_b` from the Kokoro model.
4. It calculates the resulting embedding: `result = style_a * (1.0 - ratio) + style_b * ratio`.
5. The resulting embedding is used to generate the audio.

## Benefits of Blending
- **Unique Personalities**: Create voices that are not available in the base model.
- **Fine-grained Control**: Adjust the ratio to lean more towards one speaker's tone or another.
- **Efficiency**: No additional file storage or complex model training is required; blending is performed instantly at runtime.
