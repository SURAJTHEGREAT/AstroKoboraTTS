# User Interfaces

The Kokoro TTS application provides two primary methods for interaction: a graphical Web Interface built with React for end-users and administrators, and Command Line Tools designed for direct database and system management.

1. **[Web Interface](3.1-web-interface.md)**: Details the Single Page Application, its components, and real-time streaming capabilities.
2. **[Command Line Tools](3.2-command-line-tools.md)**: Explains how to interact directly with the application's underlying data structures via CLI.
