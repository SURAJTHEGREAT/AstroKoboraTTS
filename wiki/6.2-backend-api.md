# Backend API Only Mode

For developers looking to integrate Kokoro TTS processing into an existing architecture without utilizing the provided React frontend, the FastAPI backend can be run in "API Only Mode."

## Enabling API Mode

Set the `API_ONLY` environment variable to `true` before starting the server. This tells FastAPI to require authentication for API endpoints.

```bash
API_ONLY=true uvicorn main:app --port 8000
```

You will see confirmation in the console: `Uvicorn running on http://0.0.0.0:8000`.

## API Documentation

When running in API mode, or generally interacting directly with the backend, the following core REST endpoints are available.

### 1. Generate TTS (`POST /api/tts`)

Initiates the text-to-speech engine. Returns a Server-Sent Events (SSE) stream.

```bash
curl -N -X POST http://localhost:8000/api/tts \
  -H "Content-Type: application/json" \
  -d '{"message": "Hello, world.", "voice": "af_heart"}'
```
*Note: The `-N` flag is required to read the streaming SSE response in curl.*

### 2. Blend Custom Voice (`POST /api/blend`)

Blends two existing voices to generate a new voice embedding.

```bash
curl -X POST http://localhost:8000/api/blend \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "password", "voice_name": "my_blended_voice", "voice_a": "af_heart", "voice_b": "am_adam", "ratio": 0.5}'
```

### 3. Fetch Analytics (`POST /api/analytics`)

Retrieves aggregated API usage statistics for registered clients.

```bash
curl -X POST http://localhost:8000/api/analytics \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "password"}'
```

*For more detailed request/response schemas, refer to the root `backend_api.md` file.*
