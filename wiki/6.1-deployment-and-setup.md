# Deployment and Setup

The Kokoro TTS application can be run natively using Node.js for the frontend and Python for the backend, or inside a containerized Docker environment for ease of deployment.

## Option 1: Native Execution

Running the application natively is ideal for active development.

1. **Prerequisites**: Ensure you have Node.js (v18+), Python 3.9+, and `npm` installed.
2. **Install Packages**: Navigate to the project root and run:
   ```bash
   cd frontend && npm install
   cd ../backend && pip install -r requirements.txt
   ```
3. **Setup Data Directory**: Create the folder necessary for SQLite and model storage:
   ```bash
   mkdir -p data/models
   ```
4. **Run Development Server**:
   ```bash
   cd backend && uvicorn main:app --reload --port 8000
   ```
   and in another terminal:
   ```bash
   cd frontend && npm run dev
   ```
   The frontend application will be accessible at `http://localhost:3000` and backend API at `http://localhost:8000`.

## Option 2: Docker Execution

Using Docker ensures a consistent environment and avoids the need to install Node.js directly on your host machine.

1. **Prerequisites**: Ensure Docker and Docker Compose are installed.
2. **Setup Volume Directory**:
   ```bash
   mkdir -p data/models
   ```
   *(Note for Linux users: Ensure the user running Docker has r/w permissions to `./data`, e.g., `chmod -R 777 data/`)*
3. **Build and Run**:
   ```bash
   docker-compose up --build
   ```
   The application will be exposed on port `3000`.

## Testing the Application

Automated tests are configured using `vitest`, `@testing-library/react` (for frontend), and `supertest` (for backend).

To run the complete test suite:
```bash
npm run test
```
To generate a markdown report of the test results:
```bash
npm run test:report
```
The results will be saved to `tests/reports/test-results.md`.
