# Command Line Tools

For advanced management, debugging, and direct data manipulation, administrators can interact with the Kokoro TTS application's SQLite database directly from the command line.

## Interacting with the SQLite Database

The application stores persistent metadata in a local SQLite file located at `data/metadata.db`.

### Accessing the Database

Ensure you have the `sqlite3` CLI installed on your system. You can access the database by running:

```bash
sqlite3 data/metadata.db
```

### Key Tables

- **`voices`**: Contains metadata for custom trained voices (e.g., `voice_name`, `file_path`, creation timestamp).
- **`api_clients`**: Stores registered API clients.
- **`api_client_stats`**: Logs analytics data such as total API calls, words processed per call, and TTFB.

### Useful CLI Commands

- **List Tables**:
  ```sqlite
  sqlite> .tables
  ```
- **View Custom Voices**:
  ```sqlite
  sqlite> .mode column
  sqlite> .headers on
  sqlite> SELECT * FROM voices;
  ```
- **Query Aggregated Analytics**:
  ```sqlite
  sqlite> SELECT c.client_name, COUNT(s.id) AS total_files, SUM(s.words_processed) AS total_words
          FROM api_clients c
          LEFT JOIN api_client_stats s ON c.client_id = s.client_id
          GROUP BY c.client_id;
  ```

For more detailed database interaction guidelines, refer to the project's internal `db-interact.md` file.
